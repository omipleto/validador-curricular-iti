Validador Curricular ITI

Modelo matemático formal: conjuntos, relaciones, funciones, lógica proposicional y autómata finito determinista sobre la malla de Ingeniería en Tecnologías de Información.

Resumen del Modelo Formal

El sistema transforma el reglamento curricular en un modelo ejecutable. Usa teoría de conjuntos para representar la arquitectura de la malla, relaciones binarias para la precedencia, funciones para consultas, lógica proposicional para validación y autómatas finitos para el reconocimiento de trayectorias válidas.

Conjuntos

U (universo), K (carreras), F (facultades), Pk (malla ITI), S (estudiantes), A (aprobadas), C (cursando), hab(A) (habilitadas).

Relaciones

R1 (prerrequisito: irreflexiva, asimétrica, transitiva), Rv (inscripción válida), Rd (dependencia estructural), Rf (carrera→facultad), Rs (estudiante→carrera).

Funciones

req(m): Pk → 𝒫(Pk), pct(A): 𝒫(Pk) → ℝ, hab(A): 𝒫(Pk) → 𝒫(Pk), val(C): 𝒫(Pk) → {V,F}.

Alfabetos y Lenguajes

Σ = {INS(m), APR(m), REP(m) | m ∈ Pk}

Alfabeto de eventos académicos. INS intenta inscribir, APR aprueba, REP reprueba. El autómata procesa cadenas sobre este alfabeto.

L ⊆ Σ*

Lenguaje de trayectorias válidas. w ∈ L si cada INS(m) ocurre solo tras APR de todos los prerrequisitos y la cadena termina en estado "Titulado". L3 ⊆ 𝒫(Pk) son las cargas académicas válidas.

Grafo de Prerrequisitos — R1

Grafo dirigido donde (m₁ → m₂) ∈ R1 ⊆ Pk × Pk significa "m₁ debe aprobarse antes de m₂". Haz clic en un nodo para ver su impacto en la malla.
